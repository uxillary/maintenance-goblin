# Maintenance Goblin Documentation

Welcome to the early documentation for **Maintenance Goblin**. The project is
growing into a friendly desktop companion for routine Windows maintenance.

## Getting Started
Run the application with Python:
```
python src/maintenance_goblin.py
```

### Development / Demo Mode
Use the ``--test`` flag to fake system actions and populate the log with sample
output. This is handy for demonstrating the interface without changing the
system:
```
python src/maintenance_goblin.py --test
```
