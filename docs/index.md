# Maintenance Goblin

**Maintenance Goblin** is a playful desktop companion that bundles common
Windows clean-up commands into a friendly interface.

## Features
- SFC, DISM and CHKDSK checks
- Temp file cleanup and drive optimisation
- Toggleable logs and exportable reports

## Getting Started
Run the application with Python:
```
python src/maintenance_goblin.py
```

### Development / Demo Mode
Use the ``--test`` flag to fake system actions and populate the log with sample
output. This is handy for demonstrating the interface without changing the
system:
```
python src/maintenance_goblin.py --test
```
