How it works

Windows maintenance you can understand.

This is a dashboard for genuine Windows maintenance—not a questionable “PC optimiser” promising instant speed boosts.

SFC, DISM, and system file repair

System File Checker scans protected Windows files and repairs available problems. DISM checks and restores the component store that Windows uses as a repair source. Maintenance Goblin provides a clear GUI for running both tools and reading their output.

CHKDSK and drive optimisation

CHKDSK runs as a read-only diagnostic on the C: drive—without repair, dismount, or surface-scan flags. Drive optimisation asks Windows to choose the appropriate operation for the system drive's media type.

Cleanup and administrator access

Temporary-file cleanup skips locked or inaccessible items, while Disk Cleanup opens the built-in Windows utility. Administrator permission is required because system repair and drive-maintenance commands need elevated Windows access.

Common questions

Maintenance Goblin FAQ

What is Maintenance Goblin?

Maintenance Goblin is a free, open-source Windows maintenance utility that brings trusted system tools into one approachable dashboard.

Is Maintenance Goblin safe?

Maintenance Goblin uses conservative defaults and built-in Windows tools. Its source code is public; download only from the official GitHub Releases page and verify the supplied SHA-256 checksum.

Why does Windows show Unknown Publisher?

The current executable is not code-signed, so Windows may show an Unknown Publisher or SmartScreen warning. That warning reflects the missing signature, not a claim that the file has been verified as safe.

Does Maintenance Goblin use SFC and DISM?

Yes. Its SFC GUI runs System File Checker to scan and repair protected system files, while its DISM GUI repairs the Windows component store.

Does it work on Windows 10 and Windows 11?

Yes. The current release supports Windows 10 and Windows 11.

Do I need Python installed?

No. The downloadable MaintenanceGoblin.exe is a standalone application and does not require a separate Python installation.

Does it clean the Windows registry?

No. Maintenance Goblin does not include a registry cleaner, RAM booster, or unsupported health score.

Does it work offline?

The maintenance tasks run locally and do not require Maintenance Goblin to send telemetry or show advertising. Some Windows repair operations may independently need access to Windows repair sources.

What does CHKDSK do?

Maintenance Goblin runs CHKDSK as a read-only diagnostic on the C: drive. It reports file-system information without using repair, dismount, or surface-scan options.

Why can maintenance take several minutes?

Windows system scans inspect many files and components, so their duration depends on your storage, system condition, and the work Windows needs to perform.
